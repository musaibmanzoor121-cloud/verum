# Verum — Model Card: learned AI-text classifier

> Generated by `python -m eval.train_model`. This model replaces Engine A's hand-tuned signal weights with weights **learned** from labeled data, while staying small, interpretable, and dependency-free to serve.

## What it is

- **Type:** logistic regression (numpy-gd trainer), L2 = 1.0.
- **Inputs:** 7 interpretable stylometric features computed by `app/services/features.py` — the *same* numbers Engine A's rule-based detector uses.
- **Output:** a probability 0..1 that the text is AI-written.
- **Serving:** exported to `app/services/model.json` and scored in pure Python (`services/ml_model.py`) — no numpy / scikit-learn / model download at run time, so it fits the free-tier host.
- **Trained on:** 28 samples (14 human / 14 ai) from `eval/dataset.py (built-in starter set)`.

What stands out: the model — trained from scratch, with no knowledge of the heuristic — independently ranks **buzzword** and **cadence** density as the two strongest tells, exactly the two the heuristic's author weighted highest by hand. It also confirms that **corroboration** (several signals firing at once) is a major factor, and it zeroes out **repeated openers** as redundant with cadence. That agreement is a good sign the hand-tuned engine was capturing something real, not arbitrary.

## Honest performance (leave-one-out cross-validation)

Every number below is **out-of-fold**: for each sample the model was trained on the other 27 and then asked about the one it never saw. We do *not* report training-set accuracy because on 28 rows it would look near-perfect and mean nothing.

| Model | ROC-AUC | False-positive rate | Recall (AI caught) |
|-------|---------|---------------------|--------------------|
| Heuristic (full-set, @ 0.40) | 0.903 | 0% | 79% |
| **Learned (LOO-CV, @ 0.50)** | **0.842** | 7% | 79% |
| Learned (LOO-CV, @ Youden 0.45) | 0.842 | 7% | 79% |

ROC-AUC is threshold-independent (the probability a random AI sample outranks a random human one), so it is the fairest single-number comparison between the two approaches.

## Limitations (read this before trusting the numbers)

- **Tiny dataset.** ~28 hand-written samples cannot certify a production accuracy. These figures are a sanity check and a regression guard, not a guarantee. The whole pipeline is built to scale: point `--data` at a larger labeled corpus (e.g. HC3) and retrain, no code changes.
- **Same features, so the same ceiling.** The model reads the same surface tells as the heuristic, so it is defeated by the same humanizing edits (see `ROBUSTNESS.md`). Learning the weights makes the combination principled, not the signals unbeatable.
- **Opt-in.** The live app uses the learned model only when `USE_LEARNED_MODEL=true`; the hand-tuned heuristic remains the default and the fallback if `model.json` is missing.
- **Never auto-rejects.** As everywhere in Verum, a high score routes an application to a human reviewer — it never rejects anyone.
